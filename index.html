Cómo lo resolví

Descripción

Sistema de gestión académica para un bootcamp de programación, desarrollado como evaluación del Módulo 6 (Desarrollo de aplicaciones JEE con Spring Framework). Administra cursos, prácticas, evaluaciones y notas, con tres roles distintos (administrador, docente y estudiante), autenticación por RUT y una API REST además de la interfaz web.

Desafío principal

Diseñar un sistema con permisos diferenciados por rol y un flujo de activación de cuenta en dos pasos: el administrador precarga a la persona sin contraseña, y esa persona activa su cuenta después ingresando su RUT y definiendo su clave. También había que resolver cómo registrar notas cuando un estudiante queda sin evaluar en alguna evaluación.

Solución

Implementé Spring Security para manejar autenticación y permisos por rol, separando las rutas web (Thymeleaf) de la API REST. El flujo de activación se resolvió con un estado "pendiente" hasta que la persona define su contraseña. Para notas incompletas, definí una regla explícita: si un estudiante no tiene nota registrada, se le asigna automáticamente la nota mínima (1.0), evitando datos vacíos en la planilla.

Aprendizajes

Configuración de seguridad basada en roles con Spring Security, diseño de una API REST junto con controladores MVC en el mismo proyecto, y la importancia de definir reglas de negocio explícitas en vez de dejar casos borde sin resolver.

Habilidades aplicadas

Desarrollo backend con Spring Boot, modelado de entidades JPA, autenticación y autorización basada en roles, diseño de API REST, testing con JUnit 5 y Mockito, control de cobertura con JaCoCo.
